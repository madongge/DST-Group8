## Here is the final version of our project !
1. In the navigation bar, you can search drug by entering drug ID.
2. In the drug page, "Network Graph" has been added, which contains network diagrams of drugs and related genes. When you click on a gene, it will redirect you to a webpage with relevant information about the gene.
3. In the drug page, you can search drug by entering drug name.
4. In the drug labels page, "Gene Links" has been added, which will display the related genes associated with each DrugLabel.
5. In the Dosing Guidline page, "Dose Adjustment Recommendations" has been added, which show the plot of dose adjustment.
